# The Knowledge Graph

The searchable catalogue of everything in the TVB Ontology — **dynamics**,
**networks**, **integrators**, **couplings**, **observation models**, **atlases**,
**graph generators**, and the **studies** that use them. Open at
[`/tvbo/kg`]({{base_url}}/tvbo/kg). No account needed.

Two synchronized views share the same search and filters; toggle them top-right,
next to **Sort**:

- **[List view](list-view.md)** — a filterable grid of cards. *Default.*
- **[Graph view](graph-view.md)** — an interactive node-link diagram of how
  entities relate.
