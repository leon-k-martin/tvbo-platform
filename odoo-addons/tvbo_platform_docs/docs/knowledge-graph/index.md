# The Knowledge Graph

A searchable catalogue of the TVB Ontology: dynamics, networks, integrators,
couplings, observation models, atlases, graph generators, and the studies that use
them. Open it at [`/tvbo/kg`]({{base_url}}/tvbo/kg). No account needed.

The same results appear in two views. Toggle them top-right, next to **Sort**:

- [List view](list-view.md): a filterable grid of cards (the default).
- [Graph view](graph-view.md): a node-link diagram of how entities relate.
