# Knowledge Graph — graph view

The **graph view** shows the same results as an interactive **node‑link diagram**.
Each node is an entity; edges are the relationships between them — a model belongs
to a **family**, a study **uses** a network, a network is built for an **atlas**,
and so on. It is the fastest way to see *context* and discover neighbours you did
not search for.

![The interactive graph view](img/kg-graph-view.png)

## Switch to it

In the results header, click the **graph icon** in the view toggle (top right, next
to **Sort**). Click the **list icon** to switch back. Your current search and
**Class** filters carry over to the graph unchanged.

## Move around

- **Pan** — drag the background.
- **Zoom** — scroll, or pinch on a trackpad.
- **Move a node** — drag it; the layout settles around it.
- **Hover** a node to highlight it and its immediate connections.

## Open details

**Click a node** to open the same detail view as in the list — description,
properties, equations, related entities, and the action to send it to the
[Experiment Builder](../experiment-builder/index.md). Following an edge to a
neighbouring node is often the quickest way to find, say, every study that uses a
particular connectome.

!!! tip "When to use which view"
    Use the **[list](list-view.md)** when you know roughly what you want and need to
    filter or search. Use the **graph** when you want to explore how things relate
    or stumble onto something new.
