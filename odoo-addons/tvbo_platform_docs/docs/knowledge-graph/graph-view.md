# Knowledge Graph — graph view

The same results as an interactive **node-link diagram**: nodes are entities,
edges are relationships (a model belongs to a family, a study uses a network…).
Best for seeing context and discovering neighbours.

![The interactive graph view](img/kg-graph-view.png)

- **Switch** — click the graph icon in the view toggle (top-right). Your search and
  **Class** filters carry over.
- **Move** — drag the background to pan, scroll to zoom, drag a node to reposition.
- **Open** — click a node for the same detail view as the list, including the action
  to send it to the [Experiment Builder](../experiment-builder/index.md).

!!! tip "Which view?"
    [List](list-view.md) to search and filter; **graph** to explore how things
    relate.
