# TVBO Platform Guide

Browse the Knowledge Graph, build and export a runnable experiment, and save your
work. Most of the platform needs no account, and it is free to use.

![The TVBO platform](img/home.png)

## What you can do

| Task | Where | Guide |
|---|---|---|
| Explore models, networks, couplings, studies | [`/tvbo/kg`]({{base_url}}/tvbo/kg) | [Knowledge Graph](knowledge-graph/index.md) |
| Assemble a runnable experiment and export it | [`/tvbo/configurator`]({{base_url}}/tvbo/configurator) | [Experiment Builder](experiment-builder/index.md) |
| Create a free account | [`/web/login`]({{base_url}}/web/login) | [Create an account](account/create-account.md) |
| Save models and experiments | [`/my/models`]({{base_url}}/my/models) | [Save to your account](account/save-to-account.md) |
| Run experiments in Python | [tvbo docs](https://virtual-twin.github.io/tvbo/) | [Python package](python-package/index.md) |

## A typical first session

1. Find a neural mass model or a connectome in the Knowledge Graph.
2. Open it in the Experiment Builder, or start from an example.
3. Run it on the platform, or download it as validated YAML.
4. Run the YAML in Python, or save it to your account.

Each section below has a short screencast. Working with a coding assistant? See the
[AI agents page]({{base_url}}/tvbo/agents).
