# TVBO Platform Guide

How to use **The Virtual Brain Ontology (TVBO)** platform — browse the Knowledge
Graph, build and export a runnable experiment, and keep your work in an account.
Short screencasts throughout. Free to use; most of it needs no account.

![The TVBO platform](img/home.png)

## What you can do

| You want to… | Go to | Guide |
|---|---|---|
| Explore models, networks, couplings, studies… | [`/tvbo/kg`]({{base_url}}/tvbo/kg) | [Knowledge Graph](knowledge-graph/index.md) |
| Assemble a runnable experiment and export it | [`/tvbo/configurator`]({{base_url}}/tvbo/configurator) | [Experiment Builder](experiment-builder/index.md) |
| Create a free account | [`/web/login`]({{base_url}}/web/login) | [Create an account](account/create-account.md) |

| Run experiments in Python | [tvbo docs](https://virtual-twin.github.io/tvbo/) | [Python package](python-package/index.md) |

## The four things most people do first

1. **Browse the Knowledge Graph** to find a neural mass model, a connectome, or a
   published study — in either the card list or the interactive graph.
2. **Open the Experiment Builder** and either start from an example, build one from
   scratch, or drag single components in from the Knowledge Graph.
3. **Export** the experiment as a clean, validated YAML bundle.
4. **Run it in Python** with the `tvbo` package, or **save it to your account** to
   come back to it later.
