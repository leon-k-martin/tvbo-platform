# Save models & experiments to your account

Signed in, your customized models and assembled experiments can live on the
platform under **My Models**, with **API keys** for programmatic access.

- **Save** — in the [Experiment Builder](../experiment-builder/index.md), use **Save
  to my models** (instead of, or alongside, exporting the YAML).
- **Find** — user menu → **My Models** ([`/my/models`]({{base_url}}/my/models)).
  Re-open an item in the builder or download its YAML again.
- **Private by default** — saved items stay private and do **not** appear in the
  public [Knowledge Graph](../knowledge-graph/index.md) unless you share them.
- **API keys** — create or revoke tokens at
  [`/my/api-keys`]({{base_url}}/my/api-keys).

!!! warning "Treat keys like passwords"
    An API key grants access to your account — copy it when shown, store it safely,
    and revoke it if exposed.
